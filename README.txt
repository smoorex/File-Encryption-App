# Secure File Encryptor App

This is a compiled GUI application built with Python and PyQt5.

## Supported OS:
- Windows (Tested on Windows 11)


## How to Use:
1. Double-click the .exe to launch the app.
2. Click "Browse" to select a file.
3. Click "Encrypt" or "Decrypt" as needed.
4. Encryption key is shown ONCE. Save it!
5. Paste the key in the field to decrypt the file.

## Developer:
Created using Python 3, PyQt5, Cryptography, qdarkstyle
